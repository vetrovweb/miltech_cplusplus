# 🎮 Практична робота №1: Консольна гра «Лабіринт» (C++)

## 🎯 Мета роботи
Закріпити практичні навички роботи з:
* Двовимірними динамічними масивами (`std::vector<std::vector<char>>`)
* Вкладеними циклами та умовними операторами (`if / else`, `switch`)
* Декомпозицією коду за допомогою функцій
* Перевіркою меж масивів та обробкою координат `(row, col)`

---

## 🗺️ Позначення в лабіринті

| Символ | Опис |
| :---: | :--- |
| `#` | **Стіна** (непрохідний бар'єр) |
| `.` | **Вільна клітинка** (можна переміщатися) |
| `P` | **Гравець** (Player) |
| `E` | **Вихід** (Exit) |
| `$` | **Монета** (Collectible item) |

---

## 🧱 Початкова карта лабіринту

```text
#############
#P....#.....#
#.##..#..##.#
#....##.....#
###.....###.#
#...##......#
#..$....#...#
#.####..#.#E#
#############

## 🛠️ Функціональні вимоги

[ ] Відображення: Перемальовування лабіринту у консолі після кожного ходу.
[ ] Керування: Обробка клавіш W (вгору), A (вліво), S (вниз), D (вправо).
[ ] Фізика стін: Заборона руху гравця у клітинки зі стінами (#) та виходу за межі масиву.
[ ] Предмети: При наступанні на монету ($) вона зникає, а рахунок збільшується.
[ ] Статистика в реальному часі: Постійне виведення кількості зроблених ходів та зібраних монет під лабіринтом.
[ ] Умова перемоги: При досягненні клітинки виходу (E) гра завершується та виводиться підсумковий екран.

## 🏆 Фінальний екран (перемога)

При досягненні виходу необхідно вивести наступне повідомлення:

Вітаємо!
Ви успішно пройшли лабіринт.

Статистика:
* Зібрано монет: X
* Зроблено ходів: Y

## ⚙️ Технічні вимоги до коду

Основна карта мусить зберігатися у структурі `std::vector<std::vector<char>>`.
Код має бути розділений на логічні функції (наприклад: `drawMaze()`, *movePlayer(), *checkWin() тощо).
Обов'язкова перевірка коректності координат перед виконанням ходу.
