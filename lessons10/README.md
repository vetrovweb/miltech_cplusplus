### ⚙️ Ключові концепції та теми
* 🔹 **Передача за адресою / Вказівники (`pointers`):** зміна значень змінних безпосередньо в пам'яті через `int*`.
* 🔹 **Динамічні масиви (`std::vector`):** фільтрація, сортування та маніпуляція елементами вектора.
* 🔹 **Алгоритми обробки послідовностей:** стиснення даних та видалення дублікатів, що йдуть підряд.

### 🎯 Домашнє завдання (ТЗ)

#### 📌 Завдання 1. Обмін значень двох змінних (Swap)
Звичайна функція в C++ повертає лише одне значення через `return`. За допомогою вказівників необхідно реалізувати функцію, яка змінює значення двох змінних безпосередньо в пам'яті.

**Вимоги:**
  1. Створити дві змінні у `main()`: `a = 5` та `b = 10`.
  2. Написати функцію `swapNumbers(int* x, int* y)`, яка приймає два вказівники та міняє значення за цими адресами місцями.
  3. Передати адреси змінних `a` та `b` у функцію.
  4. Вивести значення `a` та `b` до і після виклику 

---

#### 📌 Завдання 2. Рейтинг гравців (`std::vector`)
Створити програму, яка працює зі списком очок гравців, фільтрує слабкі результати та виводить топ-гравців.

**Вимоги:**
  1. Зчитати кількість елементів $N$.
  2. Зчитати $N$ цілих чисел у `std::vector<int>`.
  3. Видалити всі результати, що менші за `50`.
  4. Відсортувати вектор за спаданням.
  5. Вивести:
     * кількість гравців, що залишилися;
     * найбільший результат;
     * три найкращі результати (якщо їх менше трьох — вивести всі).

---

#### 📌 Завдання 3. Стиснення масиву (`std::vector`)
Створити програму, яка стискає послідовність однакових чисел, замінюючи однакові елементи, що йдуть підряд, одним значенням.

**Вимоги:**
  1. Зчитати $N$.
  2. Зчитати $N$ цілих чисел у `std::vector<int>`.
  3. Побудувати новий `std::vector<int>`, у якому підряд однакові елементи замінені одним.
  4. Вивести новий вектор.
  5. Додатково вивести кількість елементів, які було видалено під час стиснення.

  ```text
  1 1 1 2 2 5 5 5 5 3 3 4
  1 2 5 3 4
  ```
