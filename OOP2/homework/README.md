## 📋 Завдання 1. Система працівників

Створіть абстрактний клас `Employee`.

### 🔒 Поля (private):
* `name` — ім'я працівника (`std::string`)
* `salary` — базова зарплата (`double`)

### ⚙️ Методи:
* Конструктор
* `getName()`
* `getSalary()`
* `calculateBonus()` — чисто віртуальний метод (`= 0`)
* `showInfo()`
* Віртуальний деструктор

### 👨‍💻 Класи-нащадки:
1. **`Developer`**
    * **Додаткове поле:** кількість виконаних проєктів.
    * **Бонус:** $100 за кожен проєкт.
2. **`Manager`**
    * **Додаткове поле:** кількість працівників у команді.
    * **Бонус:** $500 + $100 за кожного працівника.

### 🧪 Приклад для перевірки:
Створити об'єкти:
* `Developer`: Vova, зарплата $3000, 5 проєктів
* `Manager`: Alex, зарплата $4000, 8 працівників

Виведіть інформацію про кожного працівника.

### 📤 Очікуваний результат:
```text
Name: Vova
Salary: 3000
Bonus: 500
Total: 3500
----------------
Name: Alex
Salary: 4000
Bonus: 1300
Total: 5300
----------------
```

## 🏦 Завдання 2. Банківські рахунки

Створіть базовий клас `BankAccount`.

### 🔒 Приватні поля:
* `owner`
* `balance`

### ⚙️ Методи:
* `deposit(double amount)`
* `withdraw(double amount)`
* `getBalance()`
* `showInfo()`

> ⚠️ **Важливо:** Потрібно контролювати баланс через методи класу. Не можна дозволити користувачу напряму змінювати `balance`.

### 💳 Класи-нащадки:
1. **`SavingsAccount`**
   * **Додаткове поле:** `interestRate`
   * **Метод:** `addInterest()` — збільшує баланс відповідно до процентної ставки.  
     *(Наприклад: Balance = 1000, Interest = 5%. Після `addInterest()` Balance = 1050)*
2. **`CreditAccount`**
   * **Додаткове поле:** `creditLimit`
   * Рахунок може мати від'ємний баланс, але не нижче кредитного ліміту.  
     *(Наприклад: Balance = 1000, Credit limit = 2000. `withdraw(2500)` дозволено -> Balance = -1500. Наступне `withdraw(1000)` заборонено, оскільки баланс стане нижчим за дозволений кредитний ліміт)*

### 📤 Очікуваний результат:
```text
Owner: Vova
Balance: 1050
Interest: 5%
----------------
Owner: Alex
Balance: -1500
Credit limit: 2000
```

## 🛒 Завдання 3. Інтернет-магазин

Створіть абстрактний клас `Product`.

### 🔒 Поля (private):
* `name`
* `price`

### ⚙️ Методи:
* `getName()`
* `getPrice()`
* `getFinalPrice()` — чисто віртуальний (`= 0`)
* `showInfo()` — віртуальний

### 📦 Класи-нащадки:
1. **`PhysicalProduct`**
   * **Додаткове поле:** `deliveryPrice`
   * **Фінальна ціна:** `price + deliveryPrice`  
     *(Наприклад: Laptop, Price: 3000, Delivery: 50 -> Final price: 3050)*
2. **`DigitalProduct`**
   * **Додаткове поле:** `discount`
   * **Фінальна ціна:** `price - discount`  
     *(Наприклад: Game, Price: 100, Discount: 20 -> Final price: 80)*

### 🧪 Приклад для перевірки:
* `Laptop` — 3000$, доставка 50$
* `Game` — 100$, знижка 20$

### 📤 Очікуваний результат:
```text
Product: Laptop
Price: 3000
Delivery: 50
Final price: 3050
----------------
Product: Game
Price: 100
Discount: 20
Final price: 80
----------------
```

## ⚔️ Завдання 4. Персонажі гри

Створіть абстрактний клас `Character`.

### 🛡️ Поля:
* `name`
* `health`
* `damage`

### ⚙️ Методи:
* `attack(Character& target)` — чисто віртуальний
* `showInfo()`
* `takeDamage(int damage)`
* Віртуальний деструктор

### 🎭 Класи-нащадки:
1. **`Warrior`** — звичайна атака: 50 damage.
2. **`Mage`** — атака: 70 damage. Але після кожної атаки маг втрачає 10 HP.
3. **`Archer`** — звичайна атака: 40 damage. Має 20% шанс завдати подвійної шкоди (`Critical attack`: 80 damage).

### 🧪 Приклад для перевірки:
* `Warrior` (HP: 200)
* `Mage` (HP: 120)

* Порядок дій:
  1. `Warrior` атакує `Mage`: `Warrior attacks Mage for 50 damage`
  2. `Mage` атакує `Warrior`: `Mage attacks Warrior for 70 damage`, `Mage loses 10 HP`

### 📤 Очікуваний результат:
```text
Warrior HP: 130
Mage HP: 60
```

## 🏆 Завдання 5. Мініпроєкт — система доставки

Самостійно спроєктуйте систему доставки.

Створіть абстрактний клас `Delivery`.

### ⚙️ Методи:
* `calculatePrice()`
* `deliver()`
* `showInfo()`

### 🚚 Типи доставки:
1. **`CourierDelivery`**
   * Має відстань у кілометрах.
   * **Формула:** `50 + 10 * distance`  
     *(Наприклад: Distance = 20 km -> Price = 50 + 10 * 20 = 250)*
2. **`NovaPostDelivery`**
   * Має вагу посилки.
   * **Формула:** `100 + 20 * weight`  
     *(Наприклад: Weight = 5 kg -> Price = 100 + 20 * 5 = 200)*
3. **`PickupDelivery`**
   * Клієнт сам забирає товар.
   * **Ціна:** `0`

### 📌 Вимоги до фінальної програми:
Створіть об'єкти:
* `CourierDelivery` — 20 km
* `NovaPostDelivery` — 5 kg
* `PickupDelivery`

Зберіть їх через вказівники базового класу `Delivery*` та обробіть у циклі.

### 📤 Очікуваний результат:
```text
Delivery: Courier
Distance: 20 km
Price: 250
Courier is delivering your package
----------------
Delivery: Nova Post
Weight: 5 kg
Price: 200
Package sent via Nova Post
----------------
Delivery: Pickup
Price: 0
Customer picks up the package
----------------
```
