# Task Manager (Менеджер завдань)

Консольний додаток мовою C++ для управління щоденними завданнями, списками справ та їхнім статусом.

---

## 📌 Функціонал

Програма працює через інтерактивне консольне меню з наступними можливостями:

1. **Показати всі задачі** — вивід повного списку збережених задач.
2. **Додати задачу** — створення нового завдання.
3. **Видалити задачу** — вилучення задачі зі списку.
4. **Позначити як виконану** — зміна статусу задачі на виконаний.
5. **Показати тільки виконані** — фільтрація та відображення лише виконаних задач.
6. **Показати тільки невиконані** — фільтрація та відображення лише активних задач.
7. **Знайти задачу** — пошук потрібного завдання за ключовими словами/назвою.
8. **Відсортувати задачі** — сортування списку за визначеним критерієм.
9. **Вийти** — завершення роботи програми.

---
